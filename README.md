# interview-algorithms

记录自己面试中遇到的算法题，用 Python 整理思路、代码和复盘，也希望能帮到准备面试的同学。

## 这里有什么

- 每题一个文件，保留力扣题号，方便查找。
- 先讲核心思路，再看带注释的代码和复杂度。
- 优先参考灵茶山艾府的题解，结合面试手写场景整理，来源见各文件顶部。
- 每个文件都带示例，可以直接运行，也可以将类和必要的导入复制到力扣提交。

5. [46. 全排列](0046_全排列.py)：回溯
6. [20. 有效的括号](0020_有效的括号.py)：栈
7. [215. 数组中的第 K 个最大元素](0215_数组中的第K个最大元素.py)：随机快速选择
8. [300. 最长递增子序列](0300_最长递增子序列.py)：动态规划 / 贪心 + 二分

## 怎么使用

Python 3.9+，只用标准库，无需安装依赖。在仓库目录下运行：

```bash
python 0042_接雨水.py
```

一次运行全部题目的示例：

```bash
python check.py
```

复习时可以先打开题目链接独立作答，再对照思路，最后关掉答案自己写一遍。后续遇到新题，按“题意 → 思路 → 复杂度 → 代码 → 示例 → 来源”继续添加即可。
