# interview-algorithms

这个repo用于记录我在面试中遇到的手撕代码题，用 Python 整理思路、代码和复盘，也希望能帮到准备面试的同学。

## 整理内容

- 每题一个文件，文件内保留力扣题号，方便查找。
- 先讲核心思路，再看带注释的代码和复杂度。
- 每个文件都带示例，可以直接运行，也可以将类和必要的导入复制到力扣提交。
