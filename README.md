# interview-algorithms

这个repo用于记录我在面试中遇到的手撕代码题，主要用python实现，用于面试前的复习和突击，也希望能帮到准备面试的同学。

## 整理内容

- 文件内保留leetcode题号，方便查找。
- 先讲核心思路，再看带注释的代码和时间空间复杂度。
- 根据面试考到的频率，我会标注不同的重要程度，以及我个人觉得需要掌握的一题多解的题目。

## 题目目录

- [20. 有效的括号](01.有效的括号.py)：栈

- [3. 无重复字符的最长子串](03.无重复字符的最长子串.py)：滑动窗口
- [200. 岛屿数量](04.岛屿数量.py)：网格 DFS（图论）
- [146. LRU 缓存](05.LRU缓存.py)：哈希表 + 双向链表
- [46. 全排列](06.全排列.py)：回溯
- [215. 数组中的第 K 个最大元素](07.数组中的第K个最大元素.py)：随机快速选择
- [300. 最长递增子序列](08.最长递增子序列.py)：动态规划 / 贪心 + 二分
- [128. 最长连续序列](09.最长连续序列.py)：哈希集合
- [15. 三数之和](10.三数之和.py)：排序 + 双指针
